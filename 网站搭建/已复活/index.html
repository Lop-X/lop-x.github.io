🚀 在新电脑上（从零到恢复）

1. 安装必备软件

  • 下载并安装 Node.js（官网下载LTS版本，一路默认安装即可）。
  • 下载并安装 Git（官网下载，安装时全部保持默认选项）。

2. 配置Git身份（重要）
打开 Git Bash，输入以下命令（替换成你的信息）：

这一步是为了让Git知道你是谁，避免之前遇到的“Author identity unknown”错误。

3. 恢复SSH密钥（或改用HTTPS）

  • 如果能找回旧密钥：将旧电脑 ~/.ssh/ 目录下的 id_rsa 和 id_rsa.pub 文件复制到新电脑相同目录，即可直接使用。
  • 如果找不回旧密钥：在Git Bash中执行 ssh-keygen -t rsa -C "你的邮箱" 生成新密钥，然后登录GitHub → Settings → SSH keys，添加新的公钥（把新 id_rsa.pub 的内容粘贴进去）。
  • 备用方案：如果觉得配SSH麻烦，可以把博客 _config.yml 里的 repo 地址改为 HTTPS格式（如 https://github.com/用户名/仓库名.git），推送时会提示输入用户名和Token。

4. 克隆博客源码到新电脑

5. 安装依赖（关键一步）

bash

这条命令会根据 package.json 自动安装Hexo及其所有插件，无需手动逐个安装。

6. 恢复主题配置（重要提醒）

  • 如果你之前修改过主题源码（比如 themes/anzhiyu 里的文件），且没有单独备份，这部分修改会丢失，需要重新应用。
  • 建议的做法：以后修改主题时，尽量使用主题支持的 “覆盖配置”功能（即在根目录下创建 _config.anzhiyu.yml 这样的文件），这样源码提交时就会包含这些自定义配置，换电脑后自动生效。

7. 验证并开始写作

如果一切顺利，你的博客就完整恢复到了新电脑上。

📋 总结：需要备份的核心文件

只要确保以下内容在源码仓库中，换电脑就能恢复：

  • source/ 文件夹（所有文章和页面）
  • themes/ 文件夹（主题文件）
  • _config.yml（站点配置）
  • package.json（依赖列表）
  • （如果是用覆盖配置）_config.anzhiyu.yml 等自定义文件
